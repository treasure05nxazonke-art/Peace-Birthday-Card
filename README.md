# Peace Birthday Card 🎉💌

A magical **interactive birthday card** for Peace!  

Click the card to open it and enjoy:  
- ❤️ Hearts floating  
- 🎈 Red balloons in the background  
- 💌 V-shaped envelope flap  
- 🎵 Plays "Happy Birthday" music  
- ✨ Smooth animations and hover effects
